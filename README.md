# Undercover at a Ball
i got this inspiration from the Barbie movie, Barbie and the three musketeers, (i saw it cause of my sister dont look at me like that) and really liked this joke, so I decided to make this fun joke as a website.

## Features
- glassmorphic design
- navbar
- footer
- image with a surprise on hover (you could have to click it a time or two if nothing changes)

### How to run locally
to run this locally on any device download this repo and double click on the index.html file
